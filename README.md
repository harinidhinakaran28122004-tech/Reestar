# Reestar Website

This project is a simple restaurant website called **Reestar**, created using HTML and basic CSS. The website displays a clean layout to showcase different food items and a contact section for customers.

The main purpose of this project is to practice basic web development concepts such as HTML structure, CSS styling, and simple page layout design.

Features:

* Food menu section with images and descriptions
* Simple and clean webpage layout
* Contact form for customer details

Technologies Used:

* HTML
* CSS
